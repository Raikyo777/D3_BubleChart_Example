# D3Example

Проект сгенерен для версии Ангуляр 17.3.2. Идея не нова, похожий проект (только менее ориентированыфй под реальный бабл чарт , зачем меньшее число имеет больший радиус ) есть на Хабре , но пришлось сильно повозиться чтобы адаптировать его под 6ю версию d3, в примере много чего уже устарело и не работает. По идее можно подсунуть тут какие нибудь данные и допилить комментарии к баблам, чтоыб датасет выглядел информативнее а не просто красивые шарики которые можно тягать в разные стороны. Если дойдут руки и будет время надо будет заняться. Но было интересно и впервые реализовать onPush стратегию , там где она актуальна .
